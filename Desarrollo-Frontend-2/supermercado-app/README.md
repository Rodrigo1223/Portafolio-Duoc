# SuperMarket Pro - Evaluación Formativa Semana 1 

Aplicación Web Single Page Application (SPA) desarrollada en React con Vite para la Evaluación Formativa 1 de la asignatura Desarrollo Frontend II en Duoc UC.

## 📌 Descripción del Proyecto
SuperMarket Pro es una plataforma interactiva que permite explorar el catálogo de productos de un supermercado, navegar entre secciones y gestionar un carrito de compras dinámico con cálculo de totales en tiempo real.

## 🛠️ Tecnologías Utilizadas
- **Frontend:** React, JavaScript (ES6+)
- **Tooling:** Vite, ESLint
- **Estilos:** CSS3 / Módulos de estilo
- **Control de Versiones:** Git & GitHub
